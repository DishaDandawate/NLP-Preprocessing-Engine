# NLP Chatbot using Hugging Face Transformers

## Project Description
This project implements a chatbot using a pre-trained transformer model (DialoGPT). 
The chatbot interacts with users and generates responses based on input.

## Technologies Used
- Python
- Hugging Face Transformers
- PyTorch

## Features
- Interactive chatbot
- Context-based responses
- Simple and user-friendly interface

## Conclusion
The project demonstrates how NLP and transformer models can be used to build intelligent conversational systems.
